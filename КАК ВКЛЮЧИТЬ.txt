DISCORD RICH PRESENCE — как включить
====================================

Нужен Application ID (это бесплатно, 1 минута):

1. Открой https://discord.com/developers/applications
2. Нажми "New Application", введи любое имя (например, "DeepSeek PC")
3. На странице приложения скопируй "Application ID" (длинное число)
4. Вставь его в файл client_id.txt в этой папке (только цифры)
5. Запусти "DiscordRP.cmd"

Готово: в профиле Discord появится статус "Играет в ..." с таймером.

Что можно поменять
------------------
Запуск с параметрами (из PowerShell):

  .\drp.ps1 -Details "Рисует Пуджа" -State "в Paint" -LargeImage "pudge"

- Details — первая строка статуса
- State — вторая строка
- LargeImage — ключ картинки из Rich Presence -> Art Assets
  (загрузи туда любую картинку и укажи её имя)

Если картинка не нужна — просто не указывай -LargeImage.
Остановить: Ctrl+C в окне.

Если Discord показывает старое название
--------------------------------------
Строка «Играет в ...» — это имя Discord-приложения, а не текст из скрипта.
Discord кэширует его, поэтому после переименования приложения может
показываться старое имя (например, «играет в змейку»).

Лечится так: полностью закрой Discord (правый клик по иконке в трее →
Quit Discord), запусти Discord заново и запусти DiscordRP.cmd.
Если хочется другое имя — переименуй приложение на
https://discord.com/developers/applications и снова перезапусти Discord.
